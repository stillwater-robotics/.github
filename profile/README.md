### Repository Naming Scheme
**_SUBMODULES:_** All lowercase, in the form `repo-name`.  
Ex. `base-internal-com-api`, `state-estimator`  
  
**_SUBMODULE PARENTS:_** Place 'ROOT' in all caps in front of the otherwise lowercase repo name `ROOT-repo-name`.  
Ex. `ROOT-simulation`
